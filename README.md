# What?

Monorepo for apps deployed on raspberry pi
at https://loic.lescoat.me 🚀

# Requirements

1. Docker Compose (`docker compose`)

# Usage

1. `git clone --recurse-submodules <this repo>`
1. Run installation steps of each submodule
1. See [website build instructions](blog/README.md) for local builds. Recipe
   sources are included in this repository under `blog/recipes/`.
1. `docker compose up --build`
